# Mesa de Ayuda TI

Aplicación web básica de mesa de ayuda (HTML, CSS y JavaScript) desarrollada para el taller de la Semana 2 de Desarrollo de Aplicaciones Web (UNIMINUTO) y desplegada en Vercel.

## Funcionalidades
- Registro de incidentes y solicitudes con consecutivo (INC-0001, REQ-0001).
- Prioridad automática con la matriz impacto × urgencia (P1 a P4).
- Acuerdos de nivel de servicio (ANS) y alerta de tickets vencidos.
- Asignación y escalamiento por niveles de soporte (N1, N2, N3).
- Gestión de estados y bitácora de cada ticket.
- Tablero con indicadores, búsqueda y filtros.
- Sección de lineamientos para implementar la mesa de ayuda.

Los datos se guardan en el navegador (localStorage).
